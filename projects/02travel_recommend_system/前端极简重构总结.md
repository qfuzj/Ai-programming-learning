# 前端极简风格重构总结

日期：2026-04-28

## 重构目标

将旅游推荐平台前端全面重构为**极简风格**，与原有 Element Plus 为主的界面彻底区分。

### 设计风格
- **主题色**: `#00E676`（鲜活绿）
- **背景**: 白色 `#FFFFFF` + 浅绿 `#E8F5E9` 点缀
- **文字**: 纯黑 `#000000`，辅助文字 `#999999`
- **整体感觉**: 大量留白、清晰排版、无多余装饰

### 设计原则
1. 优先使用**原生 HTML + CSS**，减少对 Element Plus 组件的依赖
2. 使用 CSS Grid 和 Flexbox 进行布局
3. 圆角卡片（8-12px），无多余边框
4. 按钮、输入框等交互元素统一风格
5. 响应式设计，适配移动端

## 技术要点

### CSS 架构
```
styles/
├── reset.css      # 浏览器样式重置
├── variables.css  # CSS自定义属性（颜色、间距、字体等）
└── global.css     # 全局工具类（按钮、卡片、输入框等）
```

### 关键 CSS 技巧
1. **CSS 变量**: 使用 `--color-primary: #00E676` 等变量统一管理
2. **Grid 布局**: 景点卡片网格 `grid-template-columns: repeat(4, 1fr)`
3. **Flexbox**: 导航栏、表单行等一维布局
4. **Skeleton 动画**: 使用 CSS 渐变动画，无 JS 依赖
5. **响应式**: 使用 `@media` 查询适配不同屏幕

### 与原版对比
| 特性 | 原版（Element Plus） | 新版（极简） |
|------|---------------------|----------------|
| 按钮 | `<el-button>` | `<button class="btn">` |
| 输入框 | `<el-input>` | `<input class="input">` |
| 表格 | `<el-table>` | `<table class="table">` |
| 选择器 | `<el-select>` | `<select class="input">` |
| 对话框 | `<el-dialog>` | `<div class="modal-overlay">` |
| 分页 | `<el-pagination>` | 原生上一页/下一页按钮 |
| 骨架屏 | `<el-skeleton>` | CSS 渐变动画 |
| 空状态 | `<el-empty>` | 原生 `<div class="empty">` |

## 已知问题

1. **部分页面仍依赖 composables**: 如 `ProfileView.vue` 仍使用 `useProfile`，但界面已改为原生。这是刻意的，因为 composables 封装了 API 调用逻辑，暂不删除。

2. **分页简化**: 新版使用简化的上一页/下一页按钮，不支持快速跳转到指定页。如需完整分页，可以后续添加。

3. **对话框样式**: 使用原生 `<div>` 模拟对话框，功能完整但动画效果较简单。

4. **表单验证**: 使用原生 JS 验证，错误提示使用 `alert()`，体验不如 Element Plus 的行内验证。

## 更新记录 (2026-04-29)

### 修复问题：页面跳转失败 / 登录失败

#### 1. 登录失败修复
- **问题**：登录接口返回 `{"code": 400, "message": "登录类型不能为空"}`
- **原因**：`LoginPayload` 类型要求 `loginType` 字段（`"username"` 或 `"phone"`），但登录表单缺少该字段
- **修复**：
  - `UserLoginView.vue:102` - 提交时添加 `loginType: "username"`
  - `AdminLoginView.vue:91` - 提交时添加 `loginType: "username"`

#### 2. 用户端页面 API 导入修复（6个文件）
- **原因**：页面中导入的 API 函数名与 API 文件实际导出的函数名不一致
