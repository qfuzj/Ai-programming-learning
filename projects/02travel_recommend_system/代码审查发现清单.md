# 代码审查发现清单

本清单基于 `AI分阶段生成代码任务清单.md` 的 40 项任务，对当前代码做一轮"结构 + 对齐"级扫描，记录后续可按批次消费的修复项。

> **文档基线**：2026-04-19
> **扫描深度**：浅度扫描（不做深度静态分析 / 未运行单元测试）
> **优先级标识**：
> - **P0**：前后端直接不一致 / 安全 / 功能性 bug
> - **P1**：UX 不一致、事务 / 校验边界、潜在数据漂移
> - **P2**：命名、注释、代码风格、可维护性
